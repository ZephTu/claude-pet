# 用 Seedance 给猫做逐帧动画

流程三步：出种子图 → Seedance 生成视频 → 抽帧进 App。

```bash
swift scripts/cat-seeds.swift                 # → art/seedance/seeds/*.png（绿底 1024²）
# …在 Seedance 里生成视频，按下面的文件名存进 art/seedance/videos/
scripts/cat-frames.sh art/seedance/videos     # → Resources/pet/skins/cat/frames/
swift build && .build/debug/ClaudePet         # 或 ./scripts/install.sh
```

`art/` 不进 git。蓝底：`swift scripts/cat-seeds.swift art/seedance/seeds blue`（抽帧时
自动从画面四边判断是绿幕还是蓝幕，不用告诉它）。

## 为什么全部用「首尾帧」模式

Seedance 的图生视频可以同时指定**首帧和尾帧**。这套动画全靠这一点：

- **循环**：首帧 = 尾帧 = 同一张种子图。视频结尾自然回到开头，接上就是无缝循环。
- **过渡**：首帧 = A 姿势，尾帧 = B 姿势。猫从 A 走到 B，结尾正好是 B 循环的第一帧。
- **小动作**：首帧 = 尾帧 = 种子图，中间做点别的（打哈欠、舔爪）。播放器在循环播完一圈
  时随机插进去，接缝也是同一张图。

所有片段的首尾都落在这 9 张种子图上，所以它们之间可以任意拼接。

## 生成设置

| 项 | 设置 |
| --- | --- |
| 模式 | 图生视频 · 首尾帧 |
| 比例 | **1:1**（抽帧按正方形裁，别的比例猫会被拉伸） |
| 分辨率 | 720p 足够（最后缩到 240px） |
| 时长 | 循环和小动作 5 秒；过渡选最短（抽帧会自动剪掉首尾静止的部分，再压到 1.5 秒内） |
| 镜头 | 固定，不要运镜 |

拿到视频先看三件事，不合格就重抽：背景是否一直是纯绿、猫有没有移出画面或变大变小、最后
一帧是不是回到了尾帧图。

## 通用提示词

每条提示词后面都接上这一段（下文写作「＋通用」）：

> 固定机位，静止镜头，无运镜，无缩放。纯绿色背景（#00FF00）始终保持纯色不变，无阴影、无渐变、无地面、无其他物体。角色保持原有 2D 日系卡通赛璐珞画风、线条和配色不变，橘色虎斑猫穿黑色连帽卫衣，身体比例不变，始终完整留在画面内、原地不移动。动作柔和流畅，不出现文字、特效和新道具。

## 片段清单

文件名就是片段名，播放器靠它认片段：`<姿势>.mp4` 是循环，`<姿势>@<名字>.mp4` 是小动作，
`<起>_to_<止>.mp4` 是过渡。姿势名是：`sleeping` `idle` `working` `reading` `compacting`
`awaiting-agent` `waiting` `urgent` `finished`。

缺的片段不会出错：没有循环的姿势显示原来的静止图，没有过渡的切换用 0.15 秒淡入淡出。
所以可以按优先级一批一批做，做一批抽一次。

### P1 · 过渡（首帧 = 起，尾帧 = 止）

按实际最常发生的切换排序。`working` 是忙碌状态的中心，跟它相关的过渡最值。

| 文件 | 首帧 → 尾帧 | 提示词（＋通用） |
| --- | --- | --- |
| `sleeping_to_working.mp4` | sleeping → working | 小猫醒来，揉揉眼睛，坐起来，把笔记本电脑拉到腿上打开，开始打字。 |
| `working_to_finished.mp4` | working → finished | 小猫敲完最后一下键盘，合上电脑放到脚边，站起来双手高举欢呼。 |
| `finished_to_idle.mp4` | finished → idle | 小猫放下高举的双手，满意地把手插回卫衣口袋，站好。 |
| `idle_to_sleeping.mp4` | idle → sleeping | 小猫打了个大大的哈欠，伸个懒腰，慢慢趴下蜷成一团闭眼睡着。 |
| `idle_to_working.mp4` | idle → working | 小猫坐下来，把笔记本电脑拉到腿上打开，开始打字。 |
| `working_to_idle.mp4` | working → idle | 小猫合上电脑放到一边，站起来伸展一下，双手插回口袋。 |
| `working_to_waiting.mp4` | working → waiting | 小猫停下打字抬起头，放下电脑站起来，举起一只爪子向前方招手。 |
| `waiting_to_working.mp4` | waiting → working | 小猫放下招手的爪子，点点头，坐下把电脑拉回腿上继续打字。 |
| `waiting_to_urgent.mp4` | waiting → urgent | 小猫招手越来越着急，两只爪子都挥起来，张嘴大喊，旁边弹出红色警告标志。 |
| `working_to_reading.mp4` | working → reading | 小猫把电脑放到一边，拿起一本书打开，凑近认真读。 |
| `reading_to_working.mp4` | reading → working | 小猫合上书放到一边，把电脑拉回腿上继续打字。 |
| `working_to_compacting.mp4` | working → compacting | 小猫把电脑推到一边，从旁边抱来一摞文件开始整理。 |
| `compacting_to_working.mp4` | compacting → working | 小猫把整理好的文件推到一边，把电脑拉回腿上继续打字。 |
| `working_to_awaiting-agent.mp4` | working → awaiting-agent | 小猫敲完回车，把电脑放到一边，用一只爪子托着腮等待。 |

没做直接过渡的两个姿势之间，如果 `A_to_idle` 和 `idle_to_B` 都有，播放器会经过 idle 走过去。

## 拿到视频之后

把视频全放进 `art/seedance/videos/`，每次都对整个目录跑 `scripts/cat-frames.sh`
（全量重建：删了的视频，对应的帧也会被删）。它会打印每段剪成了几帧、多长，名字对不上的
会说跳过了哪个。抠像有绿边或者缺块，把那段视频发我看，阈值在 `cat-frames.swift` 的
`key()` 里。

体积参考：一段 5 秒循环约 1.5MB（JPEG 颜色 + PNG 透明度两张图集），一段过渡约 0.5MB，
整套 30 段二十几 MB。
