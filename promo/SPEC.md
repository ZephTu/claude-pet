# SPEC — 「一张卡走完一天」

GOAL:    看完的朋友记住一句话：「session 随时可以关，事情记在卡上」，并且知道猫在余光里替你盯着所有 session。
OUTPUT:  HyperFrames，1920×1080，30 fps，中文配音，带中文字幕。
TIME:    约 185 s × 30 = 5550 帧（以配音实际时长为准，范围 165–200 s）。旁白是时间轴。
         配乐：约 84 BPM 的轻 lo-fi，一拍约 21 帧；旁白下压到 -18 dB。

LOOK:
- 大地（home stage）：macOS 桌面，暖灰 #2b2a28 纯色底，2% 颗粒，无渐变。看板以原尺寸窗口躺在桌面上，窗口阴影 0 24px 60px rgba(0,0,0,.45)。
- 产品色全部取自看板 token：
  - 窗口：bg #1a1d24 / panel #21252e / text #e8ebf1；
  - 强调色只有 accent #f2a541，用于「等你」的东西：问题、Needs you、举爪的猫；
  - #ef6f5a 用于授权和警报，#7cc4a4 用于完成。
- 字体：
  - 标题 PingFang SC Semibold，96 px，字距 -1%；
  - 字幕 PingFang SC Medium，40 px，底部居中，白字加 60% 黑描边底，位于 80% title-safe 内。
  - 在 assets/fonts 放一份 Noto Sans SC 兜底。
- 媒介：真实产品 UI 截图。看板用 `--render-board` 在 2× 下出图，数据是中文虚构数据 `board-demo-zh.js`，界面语言为 zh。猫用 `Resources/pet/skins/cat/frames` 的真实循环帧。session 列表用 `docs/previews/panel.html` 加 fixtures，通过 `--probe-film` 出帧。
- 终端：开场的 8 个终端是示意画面（不是产品界面）。用等宽字体 Menlo 26 px 画在深色窗口里，内容是 Claude Code 风格的输出。

OBJECTS:
- 猫：真实帧，桌面右下角时占画面高度约 18%，特写时占 60%。
- 光标：macOS 箭头，画面高度的 5%，从画面外进来；点击时画一圈 12 px 珊瑚红涟漪。
- 任务卡 T-014「结账：支付网关超时自动重试」：贯穿全片的主线，每次出现都是同一张卡的不同状态。
- 消息：回答合成的那一条消息，以气泡形式从看板飞进终端。
- 晚报：秘书在 Peek 里的一条回复。

MOTION:
- 进场 power3.out，18 帧；移动 power2.inOut，15 帧；镜头推拉 expo.inOut，15 帧，带运动模糊。
- 镜头只在三档之间切换：整个桌面 → 一个窗口 → 推近到 1.8× 的一个控件。
- UI 状态变化用真实的前后两张图，6 帧交叉溶解，前提是两张图只在那个控件上不同。
- 同一控件内的错峰 4 帧。

SHOTS（旁白｜画面｜交接）：
1. **钩子** 0–12 s
   - 旁白：「早上九点，你同时开着八个 Claude Code。有的在写代码，有的在跑测试——还有一个，已经等你批准好几分钟了。」
   - 画面：2×4 的终端墙在滚动；镜头慢慢后拉，露出桌面右下角举爪的猫和闪烁的 ⚠。
   - 交接：光标从画面外进来，停在猫上。
2. **猫的姿势** 12–35 s
   - 旁白：「桌面角落这只猫，替你盯着所有 session。睡着，就是都停了；敲键盘，是有人在干活；捧着书，在读代码；举起爪子，是有人在等你；晾它一分钟，它就站起来叫。」
   - 画面：推近到猫（占画面 60%），每个姿势按旁白切真实循环，左侧出现一个词的标签。
   - 交接：最后停在举爪。
3. **session 列表** 35–55 s
   - 旁白：「点一下猫，所有 session 按谁更需要你排好：需要你、刚结束、在跑。等授权的那一行，直接点 Allow，不用回终端。」
   - 画面：点击后面板展开；推近「需要你」组；Allow 被点下，那一行消失，猫回到敲键盘。
   - 交接：光标双击猫。
4. **进入看板** 55–62 s
   - 旁白：「可是 session 一多，难的不是干活，而是记住每件事做到哪了。双击小猫，打开任务看板。」
   - 画面：看板窗口从猫的位置展开到全屏，落在 Focus 页。
5. **任务卡** 62–85 s
   - 旁白：「每件事一张卡：状态、下一步、待办、日志。绑在卡上的 session，开工先读卡，干完把进展写回来。」
   - 画面：展开 T-014；依次推近状态行、下一步、待办（@me / @claude）、日志。
6. **一次答完** 85–110 s
   - 旁白：「session 要问你的事，不会淹没在对话里，而是挂在卡上，一直等到你回答。三个问题逐条选好，合成一条消息，一次发回提问的 session。」
   - 画面：用 asks 序列 1→5 的真实状态。点 Yes 并写说明 → Yes → 转待办 → 发送。消息气泡飞出看板，落进终端墙中的一格。
7. **交接** 110–130 s
   - 旁白：「傍晚，关掉这个 session 也没关系。第二天新开一个，它先读卡，从昨天停下的地方接着干——事情记在卡上，不在某一段对话里。」
   - 画面：终端关闭，画面变暗；时间戳跳到第二天 9:05；新 session 出现在卡上，日志追加一行。
8. **Peek** 130–145 s
   - 旁白：「想知道它在干嘛？点开小眼睛，看最近的对话，直接在这里回复。」
   - 画面：Peek 打开；回复框里输入一句话，发送后排进队列。
9. **定时任务** 145–160 s
   - 旁白：「有些活不用你在场。定时任务按时间表跑 Claude 或者 Shell 命令，猫关着也照跑。」
   - 画面：定时任务页，下次运行时间在倒数，一次运行的结果被点开。
10. **秘书晚报** 160–175 s
    - 旁白：「下午六点半，秘书把今天每个任务的进展，写成一份晚报交给你。」
    - 画面：秘书窗口里出现晚报，T-014 那一行被高亮。
11. **结语与片尾卡** 175–185 s
    - 旁白：「session 随时可以关，事情记在卡上。Claude Pet。」
    - 画面：镜头拉回桌面，猫睡回去，冒出 zzz。猫把标志「Claude Pet」叼进画面中央，下方是 GitHub 地址，停 3 s。

BANNED：
- 深色虚空里漂浮的小窗口；发光、粒子；紫蓝渐变；三卡并排；
- 角落里的 logo；所有元素一起淡入上滑；
- 3D 倾斜的 UI；字幕逐字重复旁白（字幕就是旁白本身，这是例外：给不方便开声音的朋友看）；
- 编造的产品按钮或功能。

QA：每个镜头的首帧、中间帧、末帧；镜头 3 的 Allow 前后；镜头 6 的气泡飞行中段；片尾卡最后一帧。
- 文字 ≥ 28 px；没有截图露出真实任务或路径；
- 字幕与旁白同步（误差 < 0.2 s）。
