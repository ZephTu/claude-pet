# Claude Pet 演示片 — 三条故事线（约 3 分钟，中文配音，16:9）

共同前提：
- 定位：HQ 为主，桌宠只简单介绍动画和 session 列表。
- 画面全部来自真实界面：
  - 看板：`--render-board` 加虚构数据 `board-demo.js`；
  - 猫：真实的逐帧动画；
  - session 列表：`docs/previews/panel.html` 加 fixtures。
- 不出现任何真实任务或 session，不用录屏，不用付费 API。

## A. 「一张卡走完一天」（推荐：有一条主线，陌生人也看得懂）

- **手法**：一天里的一个人；镜头像接力，每个画面结束时落在下一个画面的入口上（点哪里，哪里就变成下一个镜头）。
- **主线数据**：一张任务卡 `T-014 Checkout 超时重试`，从早到晚贯穿全片。
- **开头两秒**：早上 9:12，屏幕上铺着 8 个终端标签。角落里的猫举起爪子，旁边闪着 ⚠。
- **节拍**：
  1. 钩子：8 个 session，你记不住谁在等你。
  2. 猫：几个姿势（干活、读书、举爪、大叫、欢呼）。点猫看 session 列表，就地 Allow。
  3. 双击猫，进入看板。
  4. 任务卡：状态、下一步、待办。
  5. 三个问题一次答完，合成一条消息飞回提问的终端。
  6. 关掉这个 session，第二天新 session 读卡接着干（日志一行行追加）。
  7. 用 Peek 看对话并直接回复。
  8. 定时任务夜里自己跑。
  9. 18:30 秘书交来晚报。
  10. 收尾：「session 随时可以关，事情记在卡上」，然后片尾卡。
- **画面风格**：macOS 桌面作为主场景（深色壁纸），看板和猫保持原样；强调色沿用看板的珊瑚红和橙色，只用在要你处理的东西上。
- **声音**：中文旁白当时间轴；轻电子 lo-fi 本地生成；点击、消息飞出时配短音效。

## B. 「从 8 个标签到一张看板」（前后对比）

- **手法**：先演旧的做法，再演新的做法；画面从分屏收成一个。
- **开头两秒**：屏幕切成 8 格终端，有的在滚日志，有的停在「Do you want to proceed?」，光标来回乱跳。
- **节拍**：
  1. 旧方式：切 tab 找人、问题被淹没、关掉 session 就丢了上下文。
  2. 8 格收成一格：猫出现。
  3. 后面逐条对应：每个痛点各配一个 HQ 功能，依次是 Needs you、批量回答、任务卡交接、Peek、定时任务、秘书。
  4. 片尾卡。
- **画面风格**：前半段灰、乱、快；后半段画面安静，只有一个焦点。
- **风险**：容易变成「痛点 → 功能」的清单，3 分钟会显得重复。

## C. 「猫的自述」（大胆版）

- **手法**：猫当主角，用第一人称旁白：「我是你桌面上那只猫……」；全片一镜到底，镜头跟着猫从桌面钻进看板。
- **开头两秒**：猫在睡觉，zzz 飘起来。突然一个 session 等授权，猫猛地抬头看向镜头。
- **节拍**：
  1. 猫自我介绍：每个姿势在说什么。
  2. 「我记不住事情，所以我有个看板」：猫跳进看板，在卡片之间走动，介绍问题、待办和 session。
  3. 秘书出场，猫打哈欠。
  4. 猫睡回去，片尾卡。
- **画面风格**：猫的逐帧动画需要做额外的位移和走动镜头，可能会用到新的动画素材（当前素材只有原地动作）。
- **风险**：素材不够时会显得假；中文 TTS 演一只猫，语气可能不自然。

## 共同假设
- 时长 2:45–3:15，1920×1080，30fps。
- 本地 Kokoro 中文配音，配乐本地生成或不用。
- 不用 Seedance，也不花任何付费额度。
