## 日报
- 第一行：今天最要紧的一件事（进展或卡点），一句话。
- 按 project 分节，只写今天有动静的。每个 project 写三项，每项一两行，带上任务号（T-072）：
  - **进展**：做完的、合并的 PR、有了结论的事。
  - **卡点**：在等什么、等谁、等了多久。
  - **下一步**：接下来做什么、谁来做。
- 没动静的 project 合成一行列在最后。
- 最后一节"你欠别人的"：等你的 @me 待办和没回答的 ask，等得最久的排前面。

## 周报
- 开头不超过三行，总结本周。
- 按 project 写：本周进展（完成的任务、合并的 PR）、卡点、下周计划。
- "你欠别人的"写法同日报。
- 结尾提 1–2 个校准问题，放在 hq-asks 里，不写进报告文件。
